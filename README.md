# 📚 Bookstore Web Application

A full-stack Bookstore web application that allows users to browse, search, and manage books online.  
Built with **React (frontend)** and **Node.js + Express (backend)**, and uses **MongoDB** for data storage.

---

## 🚀 Features
- User Authentication (Login & Signup)
- Browse All Books
- Search Books by Name / Author
- Add Books to Cart
- Admin Panel:
  - Add New Books
  - Update Book Information
  - Delete Books
- Secure API Routes (JWT-based)
- Fully Responsive Frontend UI

---

## 🛠️ Tech Stack

| Layer | Technologies Used |
|------|------------------|
| Frontend | React, HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Database | MongoDB with Mongoose |
| Authentication | JWT + bcrypt |
| Package Manager | npm |
